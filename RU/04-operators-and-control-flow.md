# 4. Операторы и управление потоком

## Описание

Операторы комбинируют значения. Управление потоком выбирает следующий оператор. Go держит обе части небольшими. Вы пишете выражения с операторами. Вы пишете `if`, `switch` и `for` для решений и циклов.

Эта тема объясняет арифметические, сравнительные и логические операторы. Вы изучаете `if` с коротким оператором и без него. Вы изучаете `switch` по значению и `switch` по типу. Вы изучаете три формы `for`. Вы также изучаете `break`, `continue`, метки, `goto` и `defer`.

В Go нет ключевого слова `while`. `for` — единственный цикл. В Go есть `goto`. Не используйте `goto` в новом коде. Используйте `defer`, чтобы запланировать вызов, который выполняется, когда функция возвращает управление.

Используйте один термин для каждого понятия. Оператор производит значение из операндов. Инструкция меняет управление или присваивает значение. Метка называет инструкцию для `break`, `continue` или `goto`. Отложенный вызов выполняется после завершения окружающей функции.

## Арифметические, сравнительные и логические операторы

Арифметические операторы работают с числами. Операторы — `+`, `-`, `*`, `/` и `%`. `%` — остаток. `%` работает только с целыми. Целочисленное `/` усекает к нулю. `+` также конкатенирует строки.

```go
sum := 3 + 4
mod := 10 % 3
name := "Go" + "1.22"
```

`++` и `--` добавляют или вычитают единицу. Они — инструкции. Они не выражения. Нельзя написать `x = i++`. Пишите `i++` на своей строке.

Побитовые операторы работают с целыми. Операторы — `&`, `|`, `^`, `&^`, `<<` и `>>`. `^` — xor, когда у него два операнда. `^` — побитовое дополнение, когда у него один операнд. `&^` — очистка бита.

Операторы сравнения — `==`, `!=`, `<`, `<=`, `>` и `>=`. Результат имеет тип `bool`. Можно сравнивать числа, строки и другие сравнимые типы. Нельзя сравнивать `slice` (срезы), `map` (отображения) или функции друг с другом. Можно сравнивать эти типы с `nil`.

Логические операторы — `&&`, `||` и `!`. `&&` и `||` используют вычисление с коротким замыканием. Если левая сторона `&&` — `false`, Go не вычисляет правую сторону. Если левая сторона `||` — `true`, Go не вычисляет правую сторону.

```go
ok := n > 0 && name != ""
```

Операторы присваивания включают `=`, `+=`, `-=`, `*=` и `/=`. Сравнение не является присваиванием. Используйте `==` для сравнения. Используйте `=` для присваивания.

Приоритет операторов управляет порядком работы. `*` и `/` связываются сильнее, чем `+` и `-`. `&&` связывается сильнее, чем `||`. Используйте скобки, когда порядок неочевиден.

Go 1.21 и новее предоставляют встроенные `min` и `max` для упорядоченных значений. Используйте их, когда нужно меньшее или большее из двух или более значений.

## `if` / `else` (включая `if` с короткой инструкцией)

`if` выполняет блок, когда условие — `true`. Условие должно иметь тип `bool`. Скобки вокруг условия необязательны. Фигурные скобки вокруг блока обязательны.

```go
if n > 0 {
	fmt.Println("positive")
}
```

`else` выполняется, когда условие — `false`. `else if` связывает дополнительные проверки. Ключевое слово `else` должно оставаться на той же строке, что и закрывающая `}` предыдущего блока. Вставка точки с запятой делает новую строку перед `else` недопустимой.

```go
if n > 0 {
	fmt.Println("positive")
} else if n == 0 {
	fmt.Println("zero")
} else {
	fmt.Println("negative")
}
```

`if` может начинаться с короткой инструкции. Инструкция выполняется первой. Условие выполняется следующим. Имена из короткой инструкции существуют в блоке `if` и в блоках `else`.

```go
if v := len(name); v > 0 {
	fmt.Println(v)
} else {
	fmt.Println("empty")
}
```

Используйте короткую инструкцию для локального значения, которое нужно только в `if`. Частая форма — `if err := work(); err != nil`. Не используйте короткую инструкцию, когда значение должно остаться во внешней функции.

Тернарного оператора нет. Не пишите `x = cond ? a : b`. Используйте `if` и присваивайте в каждой ветке.

## `switch` (по значению и по типу)

`switch` по значению сравнивает выражение со списком веток `case`. Go выполняет первую совпавшую ветку. Go не переходит к следующей ветке, если вы не напишете `fallthrough`.

```go
switch day {
case 1:
	fmt.Println("Monday")
case 2, 3:
	fmt.Println("mid")
default:
	fmt.Println("other")
}
```

Ветка `case` может перечислить несколько значений. `default` выполняется, когда ни одна ветка не совпала. `default` необязателен. Ветки вычисляются сверху вниз.

`switch` может опустить выражение. Эта форма — `switch true`. Каждая ветка — выражение `bool`. Эта форма заменяет длинную цепочку `if` / `else if`.

`switch` может начинаться с короткой инструкции, как `if`:

```go
switch n := len(name); n {
case 0:
	fmt.Println("empty")
default:
	fmt.Println(n)
}
```

`switch` по типу сравнивает динамический тип значения интерфейса. Форма — `switch v := x.(type)`. Каждая ветка называет тип. Внутри ветки `v` имеет этот тип.

```go
func describe(x any) {
	switch v := x.(type) {
	case int:
		fmt.Println("int", v)
	case string:
		fmt.Println("string", v)
	default:
		fmt.Println("other")
	}
}
```

`any` — псевдоним для `interface{}` начиная с Go 1.18. Используйте `any` в новом коде. `switch` по типу не может использовать `fallthrough`. Используйте `switch` по типу, когда одна функция принимает несколько типов через интерфейс.

## `for` как единственный цикл (`for`, `for range`, бесконечный `for`)

`for` — единственная циклическая инструкция в Go. Нет `while` и нет `do-while`. Три формы покрывают все циклы.

Полная форма имеет `init`, условие и `post`:

```go
for i := 0; i < 3; i++ {
	fmt.Println(i)
}
```

Форма только с условием повторяется, пока условие — `true`:

```go
n := 3
for n > 0 {
	n--
}
```

Бесконечная форма не имеет условия. Цикл выполняется до `break`, `return` или `panic`:

```go
for {
	break
}
```

`for range` обходит массив, `slice`, строку, `map` или `channel` (канал). Для `slice` первое значение — индекс, а второе значение — копия элемента.

```go
for i, v := range []int{10, 20} {
	fmt.Println(i, v)
}
```

Можно опустить значения. `for i := range s` связывает индекс. `for _, v := range s` связывает элемент. `for range s` ничего не связывает.

Начиная с Go 1.22, `for i := range n` обходит целые от `0` до `n-1`, когда `n` — целое. Начиная с Go 1.22, каждая итерация имеет свою переменную цикла. Замыкание, которое захватывает `i`, видит значение этой итерации.

```go
for i := range 3 {
	fmt.Println(i) // 0, 1, 2
}
```

Обход строки даёт индекс байта и руну. Обход `map` даёт ключ и значение в случайном порядке. Обход `channel` принимает значения, пока канал не закрыт.

Не меняйте `slice` или `map` так, чтобы скрыть правила range, пока не изучите эти типы в следующей теме. Держите первые циклы простыми.

## `break`, `continue`, помеченные `break`

`break` покидает внутренний `for`, `switch` или `select`. Следующей выполняется инструкция после этого блока.

`continue` завершает текущую итерацию `for`. Цикл начинает следующую итерацию. `continue` не применяется к `switch`.

```go
for i := 0; i < 5; i++ {
	if i%2 == 0 {
		continue
	}
	if i == 3 {
		break
	}
	fmt.Println(i)
}
```

`break` внутри `switch`, который сидит в цикле, покидает только `switch`. Цикл продолжается. Используйте метку, когда нужно покинуть цикл изнутри `switch`.

Метка — идентификатор и двоеточие перед инструкцией. `break Label` покидает помеченный `for`, `switch` или `select`. `continue Label` начинает следующую итерацию помеченного `for`.

```go
Outer:
	for i := 0; i < 3; i++ {
		switch i {
		case 1:
			break Outer
		}
		fmt.Println(i)
	}
```

Помещайте метку на цикл, которым хотите управлять. Используйте ясное имя, например `Outer` или `Rows`. Не используйте метку, когда достаточно простого `return` или логического флага.

`fallthrough` не является `break`. `fallthrough` продолжает `switch` по значению в следующую ветку. `break` останавливает `switch`.

## `goto` (знать, что он есть; почти никогда не использовать)

`goto` переходит к помеченной инструкции в той же функции. Язык включает `goto`. Разработчики Go не используют `goto` как обычный инструмент управления.

```go
func demo(n int) {
	if n < 0 {
		goto Done
	}
	fmt.Println(n)
Done:
	fmt.Println("end")
}
```

`goto` не должен перепрыгивать через объявление переменной в область видимости этой переменной. Компилятор отклоняет такой переход. `goto` не должен входить в другой блок так, чтобы пропустить инициализацию.

Не используйте `goto` для построения циклов. Используйте `for`. Не используйте `goto` для выхода из вложенных блоков в новом коде. Используйте `return`, `break` или помеченный `break`. Не используйте `goto` для обработки ошибок. Используйте дополнительные строки `if` или вспомогательную функцию.

Вы изучаете `goto`, чтобы читать старый код и сообщения компилятора. Если видите `goto` в новом изменении, замените его структурированным управлением потоком.

Метка, которую использует `goto`, имеет ту же форму имени, что и метка `break`. Держите метки редкими. Два использования одного имени метки в одной функции — ошибка.

## Основы `defer`

`defer` планирует вызов функции. Вызов выполняется, когда окружающая функция возвращает управление. Вызов также выполняется, когда функция вызывает `panic`, до того как `panic` продолжается.

```go
func demo() {
	defer fmt.Println("after")
	fmt.Println("before")
}
```

Эта программа печатает `before`, затем `after`.

Аргументы отложенного вызова вычисляются на строке `defer`. Вызов ждёт. Значения аргументов не ждут.

```go
n := 1
defer fmt.Println(n) // prints 1
n = 2
```

Несколько вызовов `defer` выполняются в порядке последним пришёл — первым вышел. Последний `defer` выполняется первым.

```go
defer fmt.Println("first")
defer fmt.Println("second")
```

Эта программа печатает `second`, затем `first`.

Используйте `defer`, чтобы закрыть файл, снять блокировку мьютекса или восстановить настройку. Помещайте `defer` сразу после успешного открытия или блокировки. Тогда закрытие выполняется на каждом пути возврата.

`os.Exit` останавливает процесс и не выполняет отложенные вызовы. `return` из `main` выполняет отложенные вызовы.

`defer` в цикле планирует один вызов на итерацию. Эти вызовы ждут, пока функция не вернёт управление. Не откладывайте `Close` в длинном цикле, когда можете закрыть в той же итерации.

Именованные параметры результата могут меняться в отложенной функции. Последующая тема покрывает этот шаблон. В этой теме используйте `defer` для простой очистки и для порядка печати.
