# 3. Типы и переменные

## Описание

Go — язык со статической типизацией. Каждая переменная и каждое значение имеют тип. Компилятор проверяет типы до запуска программы. Ошибка типа останавливает сборку.

Эта тема объясняет базовые типы и то, как объявлять значения. Вы изучаете `bool`, `string`, целые числа и числа с плавающей точкой. Вы изучаете константы, `var`, короткое объявление и нулевые значения. Вы также изучаете преобразование типов, `iota` и указатели.

Go не преобразует типы молча. Вы пишете преобразование, когда типы различаются. Указатели хранят адреса. Нулевое значение указателя — `nil`.

Используйте один термин для каждого понятия. Тип называет множество значений и операций. Переменная хранит значение одного типа. Константа — именованное значение, которое не меняется. Указатель хранит адрес переменной.

## Примитивные типы: `bool`, `string`, целые числа, числа с плавающей точкой

Примитивный тип — предопределённый тип для одного значения. Основные примитивные типы — `bool`, `string`, целочисленные типы и типы с плавающей точкой. В Go также есть комплексные типы. Этот раздел сосредоточен на типах, которые вы используете первыми.

`bool` имеет два значения: `true` и `false`. Нулевое значение — `false`. Используйте `bool` для условий и флагов.

`string` — неизменяемая последовательность байтов. Нулевое значение — `""`. Исходный код Go кодирует строковые литералы как UTF-8. `len(s)` считает байты, а не символы. `for range` по строке даёт руны. Руна — кодовая точка Unicode. Тип `rune` — псевдоним `int32`. Тип `byte` — псевдоним `uint8`.

Целочисленные типы имеют фиксированный размер или размер платформы. Типы с размером — `int8`, `int16`, `int32`, `int64`, `uint8`, `uint16`, `uint32` и `uint64`. `int` и `uint` соответствуют архитектуре. На 64-битной системе они имеют 64 бита. На 32-битной системе они имеют 32 бита. `uintptr` — беззнаковое целое, которое может хранить указатель. Используйте `int` для большинства счётчиков и индексов.

Типы с плавающей точкой — `float32` и `float64`. Они следуют IEEE-754. Для нового кода предпочитайте `float64`. Нулевое значение каждого числового типа — `0`.

```go
var ok bool = true
var name string = "Go"
var n int = 22
var x float64 = 1.5
```

Не смешивайте типы в операции. `int` и `int64` — разные типы. Сначала преобразуйте одно значение. Переполнение целого числа оборачивается во время выполнения. Переполнение константы — ошибка компиляции.

## Типизированные и нетипизированные константы

Константа — значение, которое знает компилятор. Вы объявляете константу через `const`. Нельзя присвоить константе новое значение во время выполнения.

```go
const Max = 100
const Title = "demo"
const Ready = true
```

Константа типизированная или нетипизированная. Типизированная константа имеет именованный тип. Нетипизированная константа имеет род, например целое, число с плавающей точкой, строка или логическое значение. Нетипизированная константа ещё не имеет типа Go.

```go
const typedMax int = 100
const untypedMax = 100
```

Нетипизированная числовая константа имеет высокую точность в компиляторе. Её можно использовать в любом числовом контексте, который может хранить это значение. `untypedMax` может инициализировать `int`, `int64` или `float64`, когда значение помещается.

Типизированная константа должна совпадать с целевым типом. `typedMax` имеет тип `int`. Её нельзя присвоить переменной `int64` без преобразования.

Когда нетипизированная константа становится значением переменной, она принимает тип по умолчанию. Тип по умолчанию нетипизированного целого — `int`. Тип по умолчанию нетипизированного числа с плавающей точкой — `float64`. Тип по умолчанию нетипизированной строки — `string`. Тип по умолчанию нетипизированного логического значения — `bool`.

```go
n := 1      // n is int
x := 1.0    // x is float64
s := "hi"   // s is string
```

Используйте нетипизированные константы для чисел, которые могут принять многие типы. Используйте типизированную константу, когда тип является частью API.

## `var`, короткое объявление `:=` и нулевые значения

Переменная хранит значение, которое может меняться. Нулевое значение — значение переменной, которую вы не инициализируете. Каждый тип имеет нулевое значение.

`var` объявляет переменную. Можно указать тип, значение или оба:

```go
var a int
var b int = 3
var c = 3
```

Когда значение опущено, Go сохраняет нулевое значение. Нулевое значение `bool` — `false`. Нулевое значение `string` — `""`. Нулевое значение каждого числового типа — `0`. Нулевое значение указателя — `nil`.

Можно группировать объявления `var`:

```go
var (
	name string
	age  int
)
```

Короткое объявление использует `:=`. Короткое объявление работает только внутри функции. Компилятор выводит тип из значения. Хотя бы одно имя слева должно быть новым в этом блоке.

```go
func demo() {
	count := 0
	count, err := next() // err is new; count is redeclared
	_ = count
	_ = err
}
```

Повторное объявление через `:=` требует тот же тип. Повторное объявление не создаёт вторую переменную. Оно присваивает существующей переменной.

Используйте `var` на уровне пакета. Используйте `var`, когда нужно нулевое значение и нет правой части. Используйте `:=` для большинства локальных переменных, которые сразу имеют значение. Не используйте `:=`, когда выведенный тип неверен. В этом случае пишите `var x int64 = 0`.

Переменные уровня пакета существуют всю жизнь процесса. Локальные переменные существуют, пока никакой код не может их использовать. Компилятор может разместить их в стеке или в куче.

## Преобразование типов (нет неявного преобразования)

Go не преобразует типы молча. Если `x` имеет тип `T1` и нужен тип `T2`, вы пишете преобразование. Форма — `T2(x)`.

```go
var n int = 5
var m int64 = int64(n)
var f float64 = float64(n)
```

Преобразование допустимо только когда типы можно преобразовать. Числовые типы можно преобразовать в другие числовые типы. Преобразование может усечь или переполнить. `int64` в `int32` может потерять старшие биты. `float64` в `int` отбрасывает дробную часть.

```go
var x float64 = 3.9
var n int = int(x) // n is 3
```

`string` и `[]byte` преобразуются друг в друга. `string` и `[]rune` преобразуются друг в друга. `string(r)` для руны строит строку UTF-8 этой кодовой точки. `string(99)` — `"c"`, когда `99` — руна или целое, использованное как преобразование руны.

Нельзя преобразовать `bool` в целое. Нельзя сложить `int` и `int32` без преобразования. Два именованных типа с одним и тем же базовым типом преобразуются друг в друга.

```go
type Celsius float64
type Fahrenheit float64

var c Celsius = 20
var f Fahrenheit = Fahrenheit(c) // legal, but the number is not a real formula
```

Преобразование не меняет значение на месте. Преобразование создаёт новое значение. Преобразуйте на границе API. Держите один тип внутри функции, когда можете.

## `iota` и группы констант

`iota` — предопределённый идентификатор для объявлений констант. В группе `const` значение `iota` начинается с `0`. `iota` увеличивается на единицу для каждой новой строки константы в этой группе.

```go
const (
	Sunday = iota // 0
	Monday        // 1
	Tuesday       // 2
)
```

Строка, которая повторяет предыдущее выражение, всё равно использует новое `iota`. Можно написать выражение с `iota`:

```go
const (
	Read = 1 << iota // 1
	Write            // 2
	Exec             // 4
)
```

Используйте `_`, чтобы пропустить значение:

```go
const (
	_ = iota // skip 0
	One
	Two
)
```

Новый блок `const` сбрасывает `iota` в `0`. `iota` не продолжается между блоками.

Группа констант может смешивать `iota` и другие выражения. Читайте каждую строку. Компилятор копирует выражение с последней явной строки, когда у имени нет выражения.

```go
const (
	A = iota * 2 // 0
	B            // 2
	C = 100      // 100
	D            // 100
	E = iota     // 4
)
```

Используйте `iota` для связанных целочисленных кодов. Дайте группе тип, когда коды образуют API:

```go
type Day int

const (
	Sunday Day = iota
	Monday
)
```

Не используйте `iota` для значений, которые должны оставаться стабильными в сохранённом файле, если вы не контролируете каждую вставку. Новая строка в середине меняет последующие числа.

## Указатели: `&`, `*`, указатели `nil`

Указатель хранит адрес переменной. Тип указателя на `T` — `*T`. Оператор `&` берёт адрес переменной. Оператор `*` читает или записывает значение по этому адресу.

```go
n := 10
p := &n
fmt.Println(*p) // 10
*p = 20
fmt.Println(n) // 20
```

Нулевое значение указателя — `nil`. Указатель `nil` не указывает на переменную. Чтение или запись через указатель `nil` вызывает `panic`.

```go
var p *int
fmt.Println(p == nil) // true
```

Не разыменовывайте указатель, пока не знаете, что он не `nil`. Сначала сравните указатель с `nil`.

В Go нет арифметики указателей. Нельзя добавить `1` к указателю. Передавайте указатель, когда функция должна изменить переменную вызывающего. Также передавайте указатель, чтобы избежать копии большой структуры.

```go
func inc(n *int) {
	*n++
}
```

Значение указателя сравнивается как равное другому указателю, когда оба указывают на одну переменную или когда оба — `nil`.

Можно взять адрес поля структуры. Можно хранить указатель в поле структуры. Указатель на указатель имеет тип `**T`. Эта форма редка.

Компилятор может выделить локальную переменную в куче, когда вы возвращаете её адрес. Это анализ escape. Вы по-прежнему пишете `&` и `*`. Кучей вручную не управляете.

## `new` и взятие адреса значения

`new` — встроенная функция. `new(T)` выделяет переменную типа `T`. Переменная хранит нулевое значение. `new` возвращает `*T`.

```go
p := new(int)
fmt.Println(*p) // 0
*p = 7
```

Взятие адреса использует `&`. Можно написать `&x`, когда `x` — переменная. Можно написать `&T{...}` для составного литерала. Нельзя написать `&42` для целочисленного литерала.

```go
x := 7
p1 := &x

type Point struct{ X, Y int }
p2 := &Point{X: 1, Y: 2}
p3 := new(Point)
```

`new(Point)` и `&Point{}` оба дают `*Point` на нулевой `Point`. Предпочитайте `&Point{}`, когда задаёте поля. Предпочитайте именованную переменную и `&x`, когда значение уже есть. `new` полезен для нулевого `*int` или `*bool` без дополнительной строки.

Не путайте `new` с `make`. `make` создаёт `slice` (срезы), `map` (отображения) и `channel` (каналы). `make` возвращает готовое значение, а не указатель на нулевой заголовок. Эта тема не заменяет последующую тему про `slice` и `map`.

```go
p := new([]int) // p is *[]int, and *p is nil
s := make([]int, 0) // s is []int, and s is empty
```

Используйте форму, которую читатель понимает первым. Многие программы Go никогда не вызывают `new`. Обе формы корректны, когда дают указатель, который нужен.
