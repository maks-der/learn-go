# 9. Стандартная библиотека

## Описание

Стандартная библиотека Go — набор пакетов, которые поставляются с инструментарием. Вы импортируете эти пакеты без `go get`. Эта тема показывает пакеты, которые нужны большинству программ: текст, время, файлы, JSON, HTTP-клиенты, логи и флаги.

Сначала завершите темы 1–8. Предпочитайте стандартную библиотеку, когда она решает задачу. Эта тема использует Go 1.22 или новее. Для структурированных логов используйте `log/slog`. Не используйте `io/ioutil` в новом коде. Тема 10 подробно покрывает параллельность и context. Тема 11 подробно покрывает тесты.

Используйте один термин для каждого пакета. Читайте документацию пакета на pkg.go.dev или через `go doc`.

## `fmt`, `strings` и `strconv`

Пакет `fmt` форматирует значения как текст и читает текст в значения. Частые функции печати:

- `Print`, `Println`, `Printf` пишут в стандартный вывод
- `Fprint`, `Fprintln`, `Fprintf` пишут в `io.Writer`
- `Sprint`, `Sprintln`, `Sprintf` возвращают `string`

`Println` добавляет пробелы между операндами и добавляет перевод строки. `Printf` использует строку формата. Частые глаголы:

- `%v` формат по умолчанию
- `%+v` формат по умолчанию с именами полей для структур
- `%#v` синтаксис Go
- `%T` тип
- `%s` строка
- `%q` строка в кавычках
- `%d` целое
- `%f` число с плавающей точкой
- `%w` оборачивает ошибку только в `fmt.Errorf`

Функции Scan возвращают число элементов и `error`. Предпочитайте `bufio.Scanner` или `strconv`, когда разбираете одну строку или одно число.

Пакет `strings` работает с текстом. Частые функции: `Contains`, `HasPrefix`, `HasSuffix`, `Split`, `Join`, `ReplaceAll`, `TrimSpace`, `ToLower`, `ToUpper`, `Cut`. Тип `strings.Builder` строит строку с малым числом выделений. Тип `strings.Reader` реализует `io.Reader` над строкой.

Пакет `strconv` преобразует между базовыми типами и их строковыми формами. Используйте этот пакет, когда вход или выход — одно значение.

```go
n, err := strconv.Atoi("17")
s := strconv.Itoa(17)
f, err := strconv.ParseFloat("3.14", 64)
```

Каждая функция `Parse*` возвращает `error`. Проверяйте ошибку. `Atoi` — короткая форма `ParseInt` с основанием 10 и размером бит 0. `FormatFloat` нуждается в байте формата, точности и размере бит.

Предпочитайте `strings`, когда ищете фиксированную подстроку. Предпочитайте `strconv`, когда преобразуете одно число или одно bool. Используйте `fmt` для людей и простых логов.

## `time`

Пакет `time` измеряет время и часы. Тип `time.Time` — точка во времени. Тип `time.Duration` — промежуток времени. Длительность — число наносекунд `int64`.

```go
now := time.Now()
later := now.Add(2 * time.Second)
d := later.Sub(now)
```

Частые константы длительности: `time.Nanosecond`, `time.Microsecond`, `time.Millisecond`, `time.Second`, `time.Minute` и `time.Hour`.

`time.Sleep` приостанавливает текущую горутину. `time.After` возвращает канал, который получает текущее время после длительности. `time.NewTimer` и `time.NewTicker` дают таймеры, которые нужно остановить, когда они больше не нужны. Останавливайте тикер через `ticker.Stop()`.

Разбирайте и форматируйте время через раскладку. Опорное время — `Mon Jan 2 15:04:05 MST 2006`. Эта дата — ключ раскладки.

```go
t, err := time.Parse(time.RFC3339, "2024-01-02T15:04:05Z")
s := t.Format("2006-01-02")
```

Для машинного обмена используйте `time.RFC3339`. Для хранения используйте `time.UTC` или именованную локаль. `time.Now()` использует локальную зону. Преобразуйте через `t.UTC()`, когда сохраняете метку времени.

Сравнивайте времена через `t.Before`, `t.After` и `t.Equal`. Не сравнивайте значения `Time` через `==`, когда локаль может отличаться. `Equal` сравнивает мгновение.

Нулевой `Time` — год 1. Проверяйте через `t.IsZero()`. Не считайте нулевое время «сейчас».

## `os`, `path/filepath` и `io`

Пакет `os` говорит с операционной системой. Используйте `os.Open`, чтобы читать файл. Используйте `os.Create` или `os.OpenFile`, чтобы писать файл. Проверяйте ошибку. Закрывайте файл через `defer f.Close()` после успешного открытия.

```go
f, err := os.Open("data.txt")
if err != nil {
	return err
}
defer f.Close()
```

`os.ReadFile` и `os.WriteFile` покрывают маленькие файлы. `os.Args` хранит аргументы командной строки. `os.Getenv` и `os.LookupEnv` читают переменные окружения. `os.Exit` останавливает процесс и пропускает отложенные вызовы.

`os.Stdin`, `os.Stdout` и `os.Stderr` — открытые файлы. Они реализуют `io.Reader` или `io.Writer`.

Пакет `path/filepath` строит и разделяет пути для текущей операционной системы. Используйте `filepath.Join`, чтобы соединить элементы. Используйте `filepath.Base`, `filepath.Dir` и `filepath.Ext`, чтобы разделить путь. Используйте `filepath.Abs` для абсолютного пути. Используйте `filepath.WalkDir`, чтобы обойти дерево.

Не соединяйте пути через `+` и `/`. Windows использует `\`. `filepath.Join` выбирает правильный разделитель. Пакет `path` — для путей со слешами, например URL. Для путей на диске используйте `path/filepath`.

Пакет `io` определяет `Reader`, `Writer`, `Closer` и помощники. `io.Copy` копирует из читателя в писатель. `io.ReadAll` читает до EOF. `io.NopCloser` оборачивает читатель no-op `Close`. `io.EOF` помечает конец ввода. `io.MultiWriter` пишет в несколько писателей.

Не используйте `io/ioutil`. Этот пакет устарел. Функции переехали в `io` и `os`.

## `encoding/json`

Пакет `encoding/json` кодирует и декодирует JSON. `json.Marshal` превращает значение Go в `[]byte`. `json.Unmarshal` заполняет значение Go из `[]byte`.

```go
type User struct {
	Name string `json:"name"`
	Age  int    `json:"age"`
}

b, err := json.Marshal(User{Name: "Ada", Age: 36})
var u User
err = json.Unmarshal(b, &u)
```

Экспортируйте поля, которые хотите в JSON. Используйте теги структур для имён. `omitempty` опускает нулевое значение. `json:"-"` пропускает поле. Тема 5 покрывает теги.

`json.NewEncoder` пишет в `io.Writer`. `json.NewDecoder` читает из `io.Reader`. Используйте эти типы для потоков и тел HTTP.

```go
err := json.NewEncoder(w).Encode(u)
err = json.NewDecoder(r).Decode(&u)
```

Числа в объектах JSON часто декодируются в `float64`, когда цель — `map[string]any` или `any`. Используйте структуру с `int` или `json.Number`, когда нужны точные целые.

Неизвестные ключи объекта по умолчанию игнорируются при декодировании в структуру. `Decoder.DisallowUnknownFields` отклоняет лишние ключи.

Срез или карта `nil` кодируются как `null`. Пустой срез кодируется как `[]`. Пустая карта кодируется как `{}`.

Всегда проверяйте ошибку marshal и unmarshal. Не игнорируйте синтаксическую ошибку.

## Клиент `net/http`

Пакет `net/http` включает клиент и сервер. Этот раздел покрывает клиент. Тема 13 покрывает серверы.

`http.Get` и `http.Post` — короткие помощники. Они используют `http.DefaultClient`. Всегда закрывайте тело ответа.

```go
resp, err := http.Get("https://example.com")
if err != nil {
	return err
}
defer resp.Body.Close()
body, err := io.ReadAll(resp.Body)
```

Проверяйте `resp.StatusCode`. Ответ 404 — не `error` от `Get`. Ошибка — для сетевых и протокольных сбоев.

Используйте `http.NewRequestWithContext`, когда нужны метод, заголовки, тело или таймаут. Передайте context. Тема 10 покрывает context.

```go
req, err := http.NewRequestWithContext(ctx, http.MethodGet, url, nil)
req.Header.Set("Accept", "application/json")
resp, err := http.DefaultClient.Do(req)
```

`http.Client` хранит таймаут и транспорт. Задайте `Timeout` на клиенте для простого дедлайна. Переиспользуйте один `Client`. Не создавайте клиент на каждый запрос. Транспорт по умолчанию пулит соединения.

```go
client := &http.Client{Timeout: 5 * time.Second}
```

`http.NewRequest` без context старше. Предпочитайте `NewRequestWithContext`. Не игнорируйте редиректы, когда отправляете учётные данные. Настройте `CheckRedirect`, когда нужно.

Для тестов используйте `httptest.Server`. Тема 11 покрывает `httptest`.

## `log/slog` и `flag`

Пакет `log/slog` пишет структурированные логи. Запись имеет уровень, сообщение и атрибуты. Обработчик по умолчанию пишет текст. `slog.NewJSONHandler` пишет JSON.

```go
slog.Info("started", "port", 8080)
slog.Error("open failed", "err", err)
```

Уровни включают `Debug`, `Info`, `Warn` и `Error`. Используйте `slog.SetDefault`, чтобы установить логгер. Передавайте `*slog.Logger`, когда пакет не должен использовать глобальный логгер.

```go
h := slog.NewJSONHandler(os.Stderr, &slog.HandlerOptions{Level: slog.LevelInfo})
logger := slog.New(h)
logger.Info("ready", "env", "dev")
```

Держите ключи в стабильной форме. Используйте `err` для атрибута ошибки. Не логируйте секреты. Не используйте `log.Print` для новых сервисов. Старый пакет `log` подходит для крошечных инструментов.

Пакет `flag` разбирает флаги командной строки. Определяйте флаги до `flag.Parse`.

```go
port := flag.Int("port", 8080, "listen port")
name := flag.String("name", "app", "service name")
flag.Parse()
fmt.Println(*port, *name)
```

`flag.Int` возвращает `*int`. Разыменуйте указатель после `Parse`. `flag.Args` возвращает оставшиеся аргументы. `flag.Usage` печатает справку.

Не смешивайте `flag` с самодельными циклами `os.Args` в одной программе. Разбирайте один раз в `main`. Передавайте значения в остальную программу.

Для подкоманд можно использовать `flag.NewFlagSet`. Многие команды позже используют маленький внешний модуль. Начинайте с `flag`.

## Обзор темы

Эти вопросы не повторяют вопросы в разделах выше. Они покрывают всю тему.

### Вопросы

#### Теоретические вопросы

1. Как `fmt`, `strings` и `strconv` делят работу с текстом?
2. Когда выбирать `os.ReadFile`, `io.Copy` и `encoding/json` для тех же байтов на диске?
3. Как `time.Duration` и `http.Client.Timeout` работают вместе в вызове клиента?
4. Почему JSON нужны экспортируемые поля и теги, а `slog` нужны стабильные ключи атрибутов?
5. Чем владеет `main`, когда вы сочетаете `flag`, `slog` и HTTP GET?

#### Простые практические задания

1. Напишите программу, которая разбирает `-name`, логирует `hello` через `slog` и печатает имя через `fmt`.
2. Прочитайте файл JSON через `os.ReadFile` и `json.Unmarshal`. Напечатайте одно поле.
3. Отформатируйте `time.Now()` как RFC3339 и запишите в файл через `os.WriteFile`.
4. Составьте шпаргалку: одна функция из каждого пакета этой темы.

#### Средние практические задания

1. Постройте крошечный CLI: `-url` и `-timeout`. Сделайте GET URL с таймаутом клиента. Залогируйте статус и длительность через `slog`.
2. Обойдите каталог, пропустите файлы не `.json` и посчитайте объекты, которые декодируются в структуру.
3. Скопируйте стандартный ввод в файл через `io.Copy` и логируйте ошибки через `slog.Error`.

#### Сложные практические задания

1. Напишите клиент, который получает JSON, декодирует в структуру и один раз повторяет при статусе 5xx. Ограничьте ожидание через `time` и context из темы 10, если уже знаете её.
2. Замените использование `io/ioutil` в старом фрагменте на `os` и `io`. Задокументируйте каждое переименование.
