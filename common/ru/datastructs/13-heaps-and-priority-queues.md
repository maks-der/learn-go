# 13. Кучи и очереди с приоритетом

## Описание

Куча — дерево, которое хранится в массиве. Очередь с приоритетом — ADT, который снимает минимум или максимум первым. Эта тема объясняет расположение в массиве, heapify, вставку, извлечение, построение кучи, пирамидальную сортировку и два применения. Она также называет кучи Фибоначчи и pairing heaps как позднее чтение. Завершите эту тему после массивов и деревьев. Завершите графы до реализации Дейкстры с кучей.

Используйте один термин для каждого понятия. **Двоичная куча** — завершённое двоичное дерево со свойством кучи. **Мин-куча** держит каждого родителя меньше или равным своим детям. **Очередь с приоритетом** — ADT. Куча — обычная реализация.

## Двоичная куча (расположение в массиве)

**Двоичная куча** — завершённое двоичное дерево. Каждый уровень полон, кроме последнего. Последний уровень заполняется слева. Вы храните дерево в массиве. Вы не храните указатели детей.

Для массива с нумерацией с 1 (индекс 1 — корень):

- левый ребёнок i — 2i
- правый ребёнок i — 2i + 1
- родитель i — floor(i / 2)

Для массива с нумерацией с 0 (индекс 0 — корень):

- левый ребёнок i — 2i + 1
- правый ребёнок i — 2i + 2
- родитель i — floor((i − 1) / 2)

Этот справочник использует индексы **с нуля** в примерах, если строка не говорит нумерацию с 1.

```text
min-heap values: 1, 3, 2, 7, 4, 5

        1
       / \
      3   2
     / \ /
    7  4 5

array: index  0  1  2  3  4  5
       value  1  3  2  7  4  5
```

**Свойство кучи** — не свойство BST. Куча не держит полную сортировку в массиве. Единственный гарантированный порядок — родитель против ребёнка. Левый ребёнок может быть больше или меньше правого ребёнка.

Завершённая форма даёт компактный массив. Нет дыры в диапазоне индексов 0 .. n−1. Локальность лучше, чем у дерева указателей.

**Макс-куча** использует противоположное правило родителя: каждый родитель больше или равен своим детям. Выберите min или max и оставайтесь с этим правилом.

Корень — минимум в мин-куче. Find-min — Θ(1). Поиск произвольного ключа — Θ(n), если не добавить дополнительное отображение.

## Просеивание, вставка, извлечение min/max

**Просеивание вверх (sift-up)** (также bubble-up или swim) начинается в узле и меняется с родителем, пока свойство кучи не выполняется. Вставка использует просеивание вверх.

**Просеивание вниз (sift-down)** (также bubble-down, sink или heapify в узле) начинается в узле и меняется с меньшим ребёнком (мин-куча), пока свойство кучи не выполняется. Извлечение минимума использует просеивание вниз. Этот справочник использует **sift-up** и **sift-down**. **Heapify** в этом разделе означает просеивание вниз в одном индексе.

**Insert** (мин-куча):

1. Добавьте новое значение в индекс n.
2. Увеличьте n.
3. Просейте вверх с нового последнего индекса.

Время — Θ(h), и h — Θ(log n).

**Extract-min** (мин-куча):

1. Сохраните корень как результат.
2. Переместите последнее значение в корень.
3. Уменьшите n.
4. Просейте вниз с корня.
5. Верните сохранённый результат.

Время — Θ(log n).

```text
siftDown(i)  // min-heap
  while i has a child:
      s = index of smaller child
      if a[i] <= a[s]: stop
      swap a[i] and a[s]
      i = s
```

```go
func parent(i int) int { return (i - 1) / 2 }
func left(i int) int   { return 2*i + 1 }
func right(i int) int  { return 2*i + 2 }
```

Extract-max на макс-куче — тот же алгоритм с большим ребёнком.

Не удаляйте корень и не сдвигайте весь массив. Эта стоимость — Θ(n). Используйте последний элемент и просеивание вниз.

Decrease-key — более поздняя нужда (Дейкстра). Вы просеиваете вверх после уменьшения значения. Вы должны знать индекс этого значения. Простая куча в массиве не находит индекс за O(1). Добавьте отображение из ключа в индекс, если нужен decrease-key.

## Построение кучи за линейное время

Вы можете построить кучу из n элементов за Θ(n) времени. Вы не вставляете n раз. n вставок стоят Θ(n log n).

**Build-heap** (Флойд):

1. Положите n значений в массив в любом порядке.
2. Найдите индекс последнего родителя: parent(n − 1).
3. Для i от этого индекса вниз до 0 вызовите sift-down(i).

У листьев нет детей. Sift-down на листе не делает работы. Большинство узлов близко к листьям. Их пути просеивания короткие. Сумма этих длин путей — Θ(n), не Θ(n log n).

```text
buildHeap(a):
  n = length of a
  for i = parent(n - 1) down to 0:
      siftDown(i)
```

```text
n = 6, last parent = parent(5) = 2
sift-down at 2, then 1, then 0
```

После build-heap массив — куча. Он не полностью отсортированный массив.

Используйте build-heap, когда уже держите все элементы. Используйте повторную вставку, когда элементы приходят по одному.

Не доказывайте оценку Θ(n) в этой теме, если не хотите сумму. Запомните факт: build-heap линейна. Повторная вставка линерифмическая.

## Пирамидальная сортировка

**Пирамидальная сортировка (heap sort)** сортирует массив на месте макс-кучей (для возрастающего вывода).

Шаги:

1. Постройте макс-кучу на полном массиве.
2. Для end = n − 1 вниз до 1:
   - Поменяйте индекс 0 с индексом end.
   - Считайте размер кучи равным end (хвост уже на финальном месте).
   - Просейте вниз в индексе 0 в этой меньшей куче.

```text
max-heap root is the largest
swap root with last
shrink heap
sift-down
repeat
```

Время — Θ(n log n). Память — Θ(1) дополнительно, если сортируете во входном массиве. Алгоритм не стабилен. Равные ключи могут сменить порядок.

Пирамидальная сортировка — хорошее упражнение. Многие библиотеки используют другую сортировку (быструю, слиянием или смесь). Вы всё равно реализуете пирамидальную сортировку один раз. Затем вы знаете extract-max в цикле.

Не используйте пирамидальную сортировку как первый урок по кучам. Сначала реализуйте очередь с приоритетом. Затем напишите пирамидальную сортировку как клиент sift-down.

Мин-куча плюс дополнительный массив результата тоже сортирует. Эта форма использует Θ(n) дополнительной памяти. Сортировка на месте использует макс-кучу и хвост того же массива.

## Применения Дейкстры и планирования

**Очередь с приоритетом** снимает самый срочный элемент. Срочность — число: расстояние, время или приоритет.

**Дейкстра** находит кратчайшие пути в графе с неотрицательными весами рёбер. Алгоритм всегда расширяет узел с наименьшим предварительным расстоянием. Мин-куча хранит узлы по этому расстоянию. Каждый extract-min даёт следующий узел. Decrease-key (или новая вставка лучшего расстояния) обновляет узел, когда появляется более короткий путь. Вы реализуете Дейкстру в теме про графы. Выучите нужду ADT здесь: extract-min и decrease-key (или дополнительные вставки).

**Планирование.** Операционная система или пул работников могут хранить задания в куче. Следующее задание — то, у которого наименьшее время или наивысший приоритет. Insert — новое задание. Extract — «выполни это задание сейчас».

```text
priority queue ADT
  insert(element, priority)
  extract_extreme()     // min or max
  peek_extreme()
  optional: decrease_priority(element, new)
```

Другие применения: коды Хаффмана (два extract-min, одна вставка), выбор k наименьших (макс-куча размера k) и симуляция событий (время следующего события).

Отсортированный массив тоже даёт extract-min за Θ(1), если снимаете спереди. Вставка тогда Θ(n). Куча даёт и вставку, и извлечение за Θ(log n). Выбирайте кучу, когда смешиваете две операции.

Не используйте кучу для поиска по ключу как в отображении. Используйте кучу, когда всегда нужна крайность.

## Кучи Фибоначчи / pairing (только ознакомление)

**Двоичная куча** — структура, которую вы реализуете. Другие кучи существуют. Этот раздел — только ознакомление. Не реализуйте их в этой теме.

**Куча Фибоначчи** поддерживает decrease-key за амортизированную O(1) и extract-min за амортизированную O(log n). Некоторые учебные оценки Дейкстры используют этот факт. Реальные системы часто используют двоичную кучу или pairing heap. У куч Фибоначчи большая константа и сложная реализация.

**Pairing heap** проще кучи Фибоначчи. Это дерево (или лес) с простым слиянием. На практике оно часто быстрое. Точные теоретические оценки — тема исследований.

Другие имена, которые вы можете увидеть: биномиальная куча, d-арная куча, левая куча, скошенная куча. **D-арная куча** — полезный малый вариант: больше детей на узел, более мелкое дерево, другая стоимость просеивания. Вы можете прочитать d-арную после двоичной кучи.

```text
you implement:     binary heap in an array
you only name:     Fibonacci heap, pairing heap
you may read later: d-ary heap
```

Когда текст говорит «Дейкстра есть O(m + n log n) с кучей Фибоначчи», считайте это оценкой, а не спецификацией домашнего задания. Ваша первая Дейкстра может использовать двоичную кучу.
