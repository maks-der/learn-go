# 2. Структура программы и типы

## Описание

Исходный файл Go имеет фиксированный порядок. Файл начинается с предложения package. Далее идут объявления импорта. Остальные объявления идут после импортов. У каждой переменной и у каждого значения есть тип. Компилятор проверяет типы до запуска программы.

Эта тема объясняет каркас файла, имена, примитивные типы, переменные, константы и указатели. Завершите эту тему до изучения управления потоком.

Используйте один термин для каждого понятия. Пакет — каталог файлов Go с одним и тем же именем пакета. Команда — это `package main`, который содержит `func main`. Тип именует набор значений и операций. Указатель хранит адрес переменной.

---

## `package main`, `import` и `func main`

Пакет — единица, которую собирает компилятор. Все файлы `.go` в одном каталоге образуют один пакет. Эти файлы должны использовать одно имя пакета. Файл начинается с предложения package:

```go
package greet
```

Имя пакета — идентификатор. Имя пакета часто совпадает с именем папки. Имя пакета — не путь импорта. Другие файлы импортируют пакет по пути импорта.

`package main` — особый случай. `package main` определяет команду. Команда собирается в двоичный файл. Библиотечный пакет использует другое имя, например `greet`. Библиотечный пакет сам по себе не собирается в двоичный файл.

Объявление импорта называет пакет, который использует этот файл. Путь импорта — строка. Для стандартной библиотеки путь импорта — `"fmt"` или `"net/http"`. Для модуля путь импорта — путь модуля плюс папка пакета.

```go
package main

import (
	"fmt"
	"os"
)

func main() {
	fmt.Println("command")
}
```

Компилятор отклоняет неиспользуемый импорт. Удалите импорт или используйте имя из этого пакета. `gofmt` ставит пути стандартной библиотеки в первую группу. `gofmt` ставит остальные пути в следующую группу.

Точка входа программы — `func main` в `package main`. Сигнатура не имеет параметров и результатов. Среда выполнения инициализирует пакет `main`. Затем среда вызывает `func main`. Когда `main` возвращает управление, процесс завершается со статусом `0`.

Не давайте `main` параметры. Не давайте `main` результаты. Аргументы командной строки читайте из `os.Args`. Вызывайте `os.Exit`, когда нужен ненулевой статус. `os.Exit` сразу останавливает процесс. Отложенные вызовы после `os.Exit` не выполняются.

В `package main` должна быть ровно одна `func main`. Держите `main` маленькой. Логику кладите в другие функции и пакеты.

## Комментарии, идентификаторы, ключевые слова и экспортируемые имена

Комментарий — текст, который компилятор игнорирует. Строчный комментарий начинается с `//` и заканчивается в конце строки. Блочный комментарий начинается с `/*` и заканчивается `*/`. Для почти всех комментариев используйте `//`. Блочные комментарии не вкладываются.

```go
// Package greet formats short messages.
package greet

// Hello returns a greeting for name.
func Hello(name string) string {
	return "hi " + name
}
```

Комментарий пакета стоит над предложением package без пустой строки. Комментарий функции стоит над функцией. Начинайте комментарий функции с имени функции.

Идентификатор именует пакет, функцию, тип, переменную, константу или метку. Идентификатор начинается с буквы или `_`. Далее идут буквы, цифры или `_`. Эти имена допустимы: `total`, `Total`, `HTTPClient`. Эти имена недопустимы: `2x`, `user-name`.

Ключевое слово — зарезервированное слово. Нельзя использовать ключевое слово как идентификатор. Ключевые слова включают `package`, `import`, `func`, `var`, `const`, `type`, `if`, `for`, `return`, `go`, `defer` и `struct`.

Пустой идентификатор `_` отбрасывает значение. Используйте `_`, когда функция возвращает значение, которое вам не нужно.

Именуйте пакеты короткими словами в нижнем регистре. Остальные идентификаторы именуйте MixedCaps. Экспортируемое имя начинайте с заглавной буквы. Неэкспортируемое имя начинайте со строчной буквы. Акронимы в экспортируемых именах держите в полных заглавных, например `HTTP`.

Имя экспортируется, когда первая буква — заглавная буква Unicode. Другие пакеты могут использовать экспортируемое имя. Имя не экспортируется, когда первая буква — строчная буква или `_`. Другие пакеты не могут использовать неэкспортируемое имя. Правило относится к функциям, типам, переменным, константам, полям и методам.

```go
package msg

var Default = "hi" // exported

func Hello(name string) string {
	return wrap(name)
}

func wrap(name string) string { // unexported
	return Default + " " + name
}
```

Компилятор также вставляет точки с запятой. Открывающая `{` у `func`, `if` и `for` должна оставаться на той же строке. Не пишите комментарии, которые только повторяют код.

## Примитивные типы: `bool`, `string`, целые, числа с плавающей точкой

Примитивный тип — предопределённый тип для одного значения. Основные примитивные типы — `bool`, `string`, целые типы и типы с плавающей точкой.

`bool` имеет два значения: `true` и `false`. Нулевое значение — `false`. Используйте `bool` для условий и флагов.

`string` — неизменяемая последовательность байтов. Нулевое значение — `""`. Исходный код Go кодирует строковые литералы как UTF-8. `len(s)` считает байты, не символы. `for range` по строке даёт руны. Руна — кодовая точка Unicode. Тип `rune` — псевдоним `int32`. Тип `byte` — псевдоним `uint8`.

Целые типы имеют фиксированный размер или размер платформы. Типы с размером — `int8`, `int16`, `int32`, `int64`, `uint8`, `uint16`, `uint32` и `uint64`. `int` и `uint` соответствуют архитектуре. На 64-битной системе они 64 бита. Используйте `int` для большинства счётчиков и индексов.

Типы с плавающей точкой — `float32` и `float64`. Они следуют IEEE-754. Для нового кода предпочитайте `float64`. Нулевое значение каждого числового типа — `0`.

```go
var ok bool = true
var name string = "Go"
var n int = 22
var x float64 = 1.5
```

Не смешивайте типы в операции. `int` и `int64` — разные типы. Сначала преобразуйте одно значение. Переполнение целого оборачивается во время выполнения. Переполнение константы — ошибка компиляции.

## `var`, короткое объявление `:=` и нулевые значения

Переменная хранит значение, которое может меняться. Нулевое значение — значение переменной, которую вы не инициализировали. У каждого типа есть нулевое значение.

`var` объявляет переменную. Можно указать тип, значение или оба:

```go
var a int
var b int = 3
var c = 3
```

Когда значение опущено, Go сохраняет нулевое значение. Нулевое значение `bool` — `false`. Нулевое значение `string` — `""`. Нулевое значение каждого числового типа — `0`. Нулевое значение указателя — `nil`.

Объявления `var` можно группировать:

```go
var (
	name string
	age  int
)
```

Короткое объявление использует `:=`. Короткое объявление работает только внутри функции. Компилятор выводит тип из значения. Хотя бы одно имя слева должно быть новым в этом блоке.

```go
func demo() {
	count := 0
	count, err := next() // err is new; count is redeclared
	_ = count
	_ = err
}
```

Повторное объявление через `:=` требует тот же тип. Повторное объявление не создаёт вторую переменную. Оно присваивает существующей переменной.

Используйте `var` на уровне пакета. Используйте `var`, когда хотите нулевое значение и нет правой части. Используйте `:=` для большинства локальных переменных, у которых сразу есть значение. Не используйте `:=`, когда выведенный тип неверен. В таком случае пишите `var x int64 = 0`.

## Константы, `iota` и преобразование типов

Константа — значение, которое знает компилятор. Константу объявляют через `const`. Нельзя присвоить константе новое значение во время выполнения.

Константа типизированная или нетипизированная. Типизированная константа имеет именованный тип. Нетипизированная константа имеет вид: целое, число с плавающей точкой, строка или булево. Нетипизированная числовая константа имеет высокую точность в компиляторе. Её можно использовать в любом числовом контексте, который может удержать значение.

```go
const Max = 100
const typedMax int = 100
```

Когда нетипизированная константа становится значением переменной, она принимает тип по умолчанию. Тип по умолчанию нетипизированного целого — `int`. Тип по умолчанию нетипизированного числа с плавающей точкой — `float64`.

`iota` — предопределённый идентификатор для объявлений констант. В группе `const` значение `iota` начинается с `0`. `iota` растёт на один для каждой новой строки константы в этой группе. Новый блок `const` сбрасывает `iota` в `0`.

```go
const (
	Sunday = iota // 0
	Monday        // 1
	Tuesday       // 2
)

const (
	Read = 1 << iota // 1
	Write            // 2
	Exec             // 4
)
```

Используйте `_`, чтобы пропустить значение. Дайте группе тип, когда коды образуют API. Не используйте `iota` для значений, которые должны оставаться стабильными в сохранённом файле, если вы не контролируете каждую вставку.

Go не преобразует типы молча. Если `x` имеет тип `T1`, а нужен тип `T2`, пишите `T2(x)`. Числовые типы можно преобразовать в другие числовые типы. Преобразование может усечь или переполнить. Нельзя преобразовать `bool` в целое. Нельзя сложить `int` и `int32` без преобразования.

```go
var n int = 5
var m int64 = int64(n)
var x float64 = 3.9
var k int = int(x) // k is 3
```

`string` и `[]byte` преобразуются друг в друга. Преобразуйте на границе API. Внутри функции держите один тип, когда можете.

## Указатели: `&`, `*` и `nil`

Указатель хранит адрес переменной. Тип указателя на `T` — `*T`. Оператор `&` берёт адрес переменной. Оператор `*` читает или пишет значение по этому адресу.

```go
n := 10
p := &n
fmt.Println(*p) // 10
*p = 20
fmt.Println(n) // 20
```

Нулевое значение указателя — `nil`. Указатель `nil` не указывает на переменную. Чтение или запись через указатель `nil` вызывает panic. Сначала сравните указатель с `nil`.

В Go нет арифметики указателей. Нельзя добавить `1` к указателю. Передавайте указатель, когда функция должна изменить переменную вызывающего кода. Также передавайте указатель, чтобы избежать копирования большой структуры.

```go
func inc(n *int) {
	*n++
}
```

`new(T)` выделяет переменную типа `T` с нулевым значением и возвращает `*T`. Также можно написать `&T{...}` для составного литерала. Нельзя написать `&42` для целочисленного литерала. Не путайте `new` с `make`. `make` создаёт срезы, карты и каналы.

Компилятор может выделить локальную переменную в куче, когда вы возвращаете её адрес. Это escape-анализ. Вы по-прежнему пишете `&` и `*`. Кучей вручную не управляете.
