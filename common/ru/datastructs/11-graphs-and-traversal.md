# 11. Графы и обходы

## Описание

Граф — множество вершин и множество рёбер. Эта тема объясняет ориентированные и неориентированные графы, веса, списки и матрицы смежности, степень, путь, цикл, DAG, BFS и невзвешенный кратчайший путь, DFS, обнаружение цикла и топологическую сортировку.

Завершите эту тему после стеков, очередей и деревьев. Завершите эту тему до кратчайших путей и Union-Find.

Используйте один термин для каждого понятия. **Вершина** — узел графа. **Ребро** — связь между двумя вершинами. **Путь** — последовательность вершин, которая следует рёбрам. **Цикл** — путь, который возвращается к своему старту и имеет хотя бы одно ребро. **DAG** — ориентированный ациклический граф. **BFS** — поиск в ширину. **DFS** — поиск в глубину.

## Вершина, ребро, ориентированный против неориентированного, взвешенный

Граф G = (V, E). V — множество вершин. E — множество рёбер.

**Неориентированное** ребро {u, v} не имеет направления. Можно идти от u к v и от v к u. {u, v} — то же ребро, что {v, u}.

**Ориентированное** ребро (u, v) идёт от u к v. Нельзя идти назад, если (v, u) тоже не существует.

**Взвешенное** ребро имеет число: длину, стоимость или пропускную способность. **Невзвешенный** граф считает каждое ребро длиной 1.

```text
undirected unweighted:
  A — B
  |   |
  C — D

directed weighted:
  A --2--> B
  A --5--> C
```

**Петля** — ребро от вершины к себе. **Кратные рёбра** — больше одного ребра между одной парой. Этот справочник использует простые графы, если строка не говорит иное: нет петель, не больше одного неориентированного ребра на пару, не больше одного ориентированного ребра на упорядоченную пару.

n = |V| — число вершин. m = |E| — число рёбер.

**Плотный** граф имеет m около n². **Разреженный** граф имеет m намного меньше n², часто O(n).

Не смешивайте ориентированный и неориентированный на одной картинке. Рисуйте стрелки или рисуйте простые линии.

Дерево — особый неориентированный граф: связный и ациклический. Ориентированное дерево — другая картинка. Используйте слова темы 7, когда имеете в виду корневое дерево.

## Список смежности против матрицы

**Список смежности** хранит для каждой вершины список соседей (и веса, если нужны).

Память есть Θ(n + m). Обход всех соседей u есть Θ(degree(u)). Обход всех рёбер есть Θ(n + m).

**Матрица смежности** — таблица n × n. Ячейка [u][v] равна 1 (или весу), если ребро есть, иначе 0 (или ∞).

Память есть Θ(n²). Проверка «есть ли ребро (u, v)?» есть Θ(1). Обход всех соседей u есть Θ(n).

```text
vertices 0, 1, 2
edges 0—1, 1—2

list:
  0: 1
  1: 0, 2
  2: 1

matrix (undirected):
    0 1 2
  0 0 1 0
  1 1 0 1
  2 0 1 0
```

Используйте список для разреженного графа. Используйте матрицу, когда n мало или когда нужны проверки рёбер за константное время и вы можете заплатить память n².

Для неориентированного графа список хранит каждое ребро в двух списках. Матрица симметрична.

Для ориентированного графа список u хранит только исходящих соседей. Ячейка матрицы [u][v] — дуга u → v.

Не просматривайте полную матрицу, если нужны только существующие рёбра на большом разреженном графе. Этот просмотр есть Θ(n²).

**Список рёбер** — третья форма: список пар или троек. Его просто хранить. Обход соседей нуждается в просмотре всех m рёбер, пока вы не построите список.

## Степень, путь, цикл, DAG

**Степень** вершины в неориентированном графе — число инцидентных рёбер. В ориентированном графе **исходящая степень** — число исходящих рёбер. **Входящая степень** — число входящих рёбер.

**Путь** — последовательность различных вершин v0, v1, ..., vk, где каждое (vi, vi+1) — ребро (или {vi, vi+1} в неориентированном случае). **Длина** пути может считать рёбра (k) или сумму весов.

**Цикл** — замкнутый обход с хотя бы одним ребром, который не повторяет вершины, кроме старта и конца. (Точные формулировки учебников различаются. Этот справочник использует простой цикл: нет повторённой вершины, кроме замыкания.)

Неориентированный граф **связный**, если у каждой пары вершин есть путь. Ориентированный граф **сильно связный**, если у каждой пары есть ориентированный путь в обоих направлениях. **Слабо связный** игнорирует направление.

**DAG** — ориентированный граф без ориентированного цикла.

```text
DAG:
  A → B → D
  A → C → D

not a DAG:
  A → B → A
```

DAG моделируют задачи с предпосылками. Топологической сортировке (позже в этой теме) нужен DAG.

Факт **рукопожатий**: сумма степеней в неориентированном графе есть 2m. Каждое ребро добавляет 1 к двум степеням.

Не называйте ориентированный цикл неориентированным циклом без осторожности. Один рисунок может иметь ориентированный цикл и всё ещё быть связным как неориентированная картинка.

## BFS и невзвешенный кратчайший путь

**Поиск в ширину (BFS)** посещает вершины в порядке невзвешенного расстояния от старта s. BFS использует **очередь**. У каждого ребра длина 1.

Идея:

1. Поставьте dist[s] = 0. Поставьте dist[v] = ∞ для каждой другой вершины.
2. Сделайте enqueue s. Пометьте s как посещённую.
3. Пока очередь не пуста, сделайте dequeue u. Для каждого непосещённого соседа v у u поставьте dist[v] = dist[u] + 1, пометьте v посещённой, сделайте enqueue v.

```text
s=0
0 — 1 — 2
    |
    3

queue order: 0, 1, 2, 3   (if neighbor order is 1 then 2 from 0, and 3 from 1)
dist: 0:0  1:1  2:1  3:2
```

Посещение-при-enqueue — обычная невзвешенная форма. Вы помечаете v, когда впервые находите v. Это первое нахождение — кратчайший путь в числе рёбер.

Храните **parent[v] = u**, когда ставите dist[v]. Восстановите путь от s к t, идя по parent от t назад к s, затем разверните список.

BFS на неявной сетке — тот же алгоритм. Вершины — ячейки. Соседи приходят из функции соседей.

Время есть Θ(n + m) на списке смежности. Каждая вершина входит в очередь не больше одного раза. Каждое ребро просматривается константное число раз.

BFS не вычисляет взвешенные кратчайшие пути. Малый вес на длинном пути может выиграть. Используйте Дейкстру или Беллмана–Форда (тема 12).

Не используйте стек для этого порядка. Стек даёт DFS, не кратчайшие невзвешенные пути.

## DFS, обнаружение цикла, топологическая сортировка

**Поиск в глубину (DFS)** идёт как можно глубже по одному пути, затем возвращается. DFS использует **стек вызовов** (рекурсия) или **явный стек**.

Полезный DFS записывает два времени на вершину:

- время **обнаружения**: шаг, когда вы впервые входите в вершину
- время **завершения**: шаг, когда вы покидаете вершину после всех потомков

Цвет или состояние помогает:

- **белый:** не видели
- **серый:** обнаружена, не завершена (на стеке рекурсии)
- **чёрный:** завершена

**Обнаружение цикла в ориентированном графе.** **Обратное ребро** идёт к серой вершине. Это ребро замыкает ориентированный цикл.

**Обнаружение цикла в неориентированном графе.** Ребро к уже обнаруженной вершине, которая не родитель, — ребро цикла. Проверка родителя нужна, потому что древесное ребро появляется в обоих направлениях в списке.

**Топологическая сортировка** DAG — порядок вершин такой, что каждое ориентированное ребро идёт от более ранней вершины к более поздней.

Один метод: запустить DFS. После завершения графа перечислите вершины в **убывающем времени завершения**. Этот список — топологический порядок, если граф — DAG.

```text
A → B → D
A → C → D

one topological order: A, B, C, D
another: A, C, B, D
```

Второй метод: алгоритм Кана. Повторно делайте dequeue вершины с входящей степенью 0. Уменьшайте входящие степени её соседей. Если не можете сделать dequeue n вершин, цикл есть.

Время DFS на списке есть Θ(n + m). Время топологической сортировки то же.

Не запускайте топологическую сортировку на графе, в котором может быть цикл, без проверки цикла.

DFS не вычисляет невзвешенные кратчайшие пути. Порядок посещения — не по расстоянию.
