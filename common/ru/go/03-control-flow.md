# 3. Управление потоком

## Описание

Операторы комбинируют значения. Управление потоком выбирает следующий оператор. Go держит обе части маленькими. Вы пишете выражения с операторами. Вы пишете `if`, `switch` и `for` для решений и циклов.

Эта тема объясняет арифметические, сравнительные и логические операторы. Вы изучаете `if` и `else`. Вы изучаете value switch и type switch. Вы изучаете `for` как единственный цикл. Также изучаете `break`, `continue`, помеченные break и `defer`.

В Go нет ключевого слова `while`. `for` — единственный цикл. Используйте `defer`, чтобы запланировать вызов, который выполнится, когда функция вернёт управление.

Используйте один термин для каждого понятия. Оператор даёт значение из операндов. Инструкция меняет управление или присваивает значение. Отложенный вызов выполняется после завершения окружающей функции.

## Арифметические, сравнительные и логические операторы

Арифметические операторы работают с числами. Операторы: `+`, `-`, `*`, `/` и `%`. `%` — остаток. `%` работает только с целыми. Целое `/` усекает к нулю. `+` также склеивает строки.

```go
sum := 3 + 4
mod := 10 % 3
name := "Go" + "1.22"
```

`++` и `--` добавляют или вычитают один. Это инструкции. Это не выражения. Нельзя написать `x = i++`. Пишите `i++` на своей строке.

Побитовые операторы работают с целыми. Операторы: `&`, `|`, `^`, `&^`, `<<` и `>>`. `^` — xor, когда у него два операнда. `^` — побитовое дополнение, когда у него один операнд.

Операторы сравнения: `==`, `!=`, `<`, `<=`, `>` и `>=`. Результат имеет тип `bool`. Можно сравнивать числа, строки и другие сравнимые типы. Нельзя сравнивать срезы, карты или функции друг с другом. Эти типы можно сравнивать с `nil`.

Логические операторы: `&&`, `||` и `!`. `&&` и `||` используют короткое замыкание. Если левая сторона `&&` — `false`, Go не вычисляет правую сторону. Если левая сторона `||` — `true`, Go не вычисляет правую сторону.

```go
ok := n > 0 && name != ""
```

Операторы присваивания включают `=`, `+=`, `-=`, `*=` и `/=`. Сравнение — не присваивание. Используйте `==` для сравнения. Используйте `=` для присваивания.

Приоритет операторов управляет порядком работы. `*` и `/` связываются сильнее, чем `+` и `-`. `&&` связывается сильнее, чем `||`. Используйте скобки, когда порядок неочевиден.

Go 1.21 и новее дают встроенные `min` и `max` для упорядоченных значений.

## `if` / `else`

`if` выполняет блок, когда условие — `true`. Условие должно иметь тип `bool`. Скобки вокруг условия необязательны. Фигурные скобки вокруг блока обязательны.

```go
if n > 0 {
	fmt.Println("positive")
}
```

`else` выполняется, когда условие — `false`. `else if` связывает дополнительные проверки. Ключевое слово `else` должно оставаться на той же строке, что и закрывающая `}` предыдущего блока. Вставка точек с запятой делает новую строку перед `else` недопустимой.

```go
if n > 0 {
	fmt.Println("positive")
} else if n == 0 {
	fmt.Println("zero")
} else {
	fmt.Println("negative")
}
```

`if` может начинаться с короткой инструкции. Инструкция выполняется первой. Затем выполняется условие. Имена из короткой инструкции существуют в блоке `if` и в блоках `else`.

```go
if v := len(name); v > 0 {
	fmt.Println(v)
} else {
	fmt.Println("empty")
}
```

Используйте короткую инструкцию для локального значения, которое нужно только в `if`. Частая форма — `if err := work(); err != nil`. Не используйте короткую инструкцию, когда значение должно остаться во внешней функции.

Тернарного оператора нет. Не пишите `x = cond ? a : b`. Используйте `if` и присваивайте в каждой ветке.

## `switch` (по значению и по типу)

Value `switch` сравнивает выражение со списком веток. Go выполняет первую совпавшую ветку. Go не проваливается в следующую ветку, если вы не напишете `fallthrough`.

```go
switch day {
case 1:
	fmt.Println("Monday")
case 2, 3:
	fmt.Println("mid")
default:
	fmt.Println("other")
}
```

Ветка может перечислить несколько значений. `default` выполняется, когда ни одна ветка не совпала. `default` необязателен. Ветки вычисляются сверху вниз.

У `switch` можно опустить выражение. Эта форма — `switch true`. Каждая ветка — выражение `bool`. Эта форма заменяет длинную цепочку `if` / `else if`.

`switch` может начинаться с короткой инструкции, как `if`.

Type switch сравнивает динамический тип значения интерфейса. Форма — `switch v := x.(type)`. Каждая ветка называет тип. Внутри ветки `v` имеет этот тип.

```go
func describe(x any) {
	switch v := x.(type) {
	case int:
		fmt.Println("int", v)
	case string:
		fmt.Println("string", v)
	default:
		fmt.Println("other")
	}
}
```

`any` — псевдоним `interface{}` с Go 1.18. В новом коде используйте `any`. Type switch не может использовать `fallthrough`. Используйте type switch, когда одна функция принимает несколько типов через интерфейс.

## `for` как единственный цикл (`for`, `for range`)

`for` — единственный оператор цикла в Go. Нет `while` и нет `do-while`. Три формы покрывают все циклы.

Полная форма имеет init, условие и post:

```go
for i := 0; i < 3; i++ {
	fmt.Println(i)
}
```

Форма только с условием повторяется, пока условие — `true`:

```go
n := 3
for n > 0 {
	n--
}
```

Бесконечная форма не имеет условия. Цикл идёт, пока не будет `break`, `return` или `panic`:

```go
for {
	break
}
```

`for range` обходит массив, срез, строку, карту или канал. Для среза первое значение — индекс, второе — копия элемента.

```go
for i, v := range []int{10, 20} {
	fmt.Println(i, v)
}
```

Значения можно опустить. `for i := range s` связывает индекс. `for _, v := range s` связывает элемент. `for range s` ничего не связывает.

С Go 1.22 `for i := range n` обходит целые от `0` до `n-1`, когда `n` — целое. С Go 1.22 у каждой итерации своя переменная цикла. Замыкание, которое захватывает `i`, видит значение этой итерации.

```go
for i := range 3 {
	fmt.Println(i) // 0, 1, 2
}
```

Range по строке даёт индекс байта и руну. Range по карте даёт ключ и значение в случайном порядке. Range по каналу принимает значения, пока канал не закрыт.

## `break`, `continue` и помеченные break

`break` покидает внутренний `for`, `switch` или `select`. Далее выполняется инструкция после этого блока.

`continue` завершает текущую итерацию `for`. Цикл начинает следующую итерацию. `continue` не применяется к `switch`.

```go
for i := 0; i < 5; i++ {
	if i%2 == 0 {
		continue
	}
	if i == 3 {
		break
	}
	fmt.Println(i)
}
```

`break` внутри `switch`, который сидит в цикле, покидает только `switch`. Цикл продолжается. Используйте метку, когда нужно покинуть цикл изнутри `switch`.

Метка — идентификатор и двоеточие перед инструкцией. `break Label` покидает помеченный `for`, `switch` или `select`. `continue Label` начинает следующую итерацию помеченного `for`.

```go
Outer:
	for i := 0; i < 3; i++ {
		switch i {
		case 1:
			break Outer
		}
		fmt.Println(i)
	}
```

Ставьте метку на цикл, которым хотите управлять. Используйте ясное имя, например `Outer` или `Rows`. Не используйте метку, когда достаточно простого `return` или булева флага.

`fallthrough` — не `break`. `fallthrough` продолжает value `switch` в следующую ветку. `break` останавливает `switch`.

В Go есть `goto`. `goto` прыгает к помеченной инструкции в той же функции. Не используйте `goto` в новом коде. Используйте `for`, `return` или помеченный `break`.

## `defer`

`defer` планирует вызов функции. Вызов выполняется, когда окружающая функция возвращает управление. Вызов также выполняется, когда функция паникует, до продолжения panic.

```go
func demo() {
	defer fmt.Println("after")
	fmt.Println("before")
}
```

Эта программа печатает `before`, затем `after`.

Аргументы отложенного вызова вычисляются на строке `defer`. Вызов ждёт. Значения аргументов не ждут.

```go
n := 1
defer fmt.Println(n) // prints 1
n = 2
```

Несколько вызовов `defer` выполняются в порядке last-in, first-out. Последний `defer` выполняется первым.

```go
defer fmt.Println("first")
defer fmt.Println("second")
```

Эта программа печатает `second`, затем `first`.

Используйте `defer`, чтобы закрыть файл, разблокировать мьютекс или восстановить настройку. Ставьте `defer` сразу после успешного открытия или блокировки. Тогда закрытие выполнится на каждом пути возврата.

`os.Exit` останавливает процесс и не выполняет отложенные вызовы. `return` из `main` отложенные вызовы выполняет.

`defer` в цикле планирует один вызов на итерацию. Эти вызовы ждут, пока функция не вернёт управление. Не откладывайте `Close` в длинном цикле, когда можно закрыть в той же итерации.

Именованные параметры результата могут меняться в отложенной функции. Тема 4 покрывает этот шаблон. В этой теме используйте `defer` для простой очистки и для порядка печати.

3. Поставьте `defer fmt.Println(i)` внутри `for`, который выполняется три раза. Напечатайте порядок чисел после тела цикла.

#### Сложные практические задания

## Обзор темы

Эти вопросы не повторяют вопросы в разделах выше. Они покрывают всю тему.

### Вопросы

#### Теоретические вопросы

1. Как операторы, `if` и `switch` разделяют тип `bool`?
2. Когда выбирать `for range` вместо полного `for`, и когда выбирать бесконечный `for`?
3. Как помеченный `break` и `defer` каждый меняют путь выхода из вложенной работы?
4. Почему `goto` в этом справочнике — навык чтения, а не инструмент письма?
5. Когда функция возвращает управление изнутри `switch` в цикле, какие отложенные вызовы выполняются и что делает цикл?

#### Простые практические задания

1. Напишите программу, которая использует `%`, `&&`, `if` и полный `for`, чтобы печатать нечётные числа ниже `10`.
2. Добавьте value `switch`, который помечает каждое число как `small`, `mid` или `big`. Оставьте цикл.
3. Пройдите range по срезу слов. Делайте `continue` на пустом слове. Отложите одну итоговую печать, которая выполняется в конце `main`.
4. Посчитайте пробелы в предложении через `for range` по строке и сравнение. Напечатайте счётчик.

#### Средние практические задания

1. Разберите флаги из `os.Args` короткими инструкциями `if` и `switch` по слову команды. Включите `help` и путь неизвестной команды.
2. Обойдите срез через `for range`. Используйте type switch по значениям `any` в срезе. Прервите помеченный цикл, когда увидите отрицательный `int`.
3. Совместите очистку `defer` с цепочкой `if err != nil` в одной функции, которая пишет временный файл. Покажите путь успеха и путь ошибки.

#### Сложные практические задания

1. Постройте крошечный цикл REPL: бесконечный `for`, `switch` по текстовым командам, `continue` на пустом вводе, `break` на `quit` и `defer` прощальной печати. Отклоните `goto`.
